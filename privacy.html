Privacy Policy — Noor Ayah

Last updated: 20 August 2026

Noor Ayah is designed to minimize personal-data collection. The generator fetches public Quran text, translations, and recitation audio and stores local generation state so that verses are not repeated.

When a user authorizes the optional TikTok draft-upload integration, the project uses the OAuth access token and open ID supplied by TikTok only to upload selected videos as drafts to the authorized account. Tokens must be kept in a local ignored file or server-side secret store and must never be committed to source control. Noor Ayah does not sell personal information or use TikTok authorization data for advertising.

Third-party services, including Quran data providers and TikTok, process requests according to their own privacy policies and terms. Users may revoke authorization through TikTok and may delete locally stored tokens and generation history at any time.

Contact: GitHub issue tracker.
