## Quran TikTok Channel

تمت إضافة مشروع مولّد مقاطع القرآن العمودية داخل [`quran_tiktok/`](./quran_tiktok/).

للتشغيل:

```bash
cd quran_tiktok
python3 -m pip install -r requirements.txt
python3 run_channel.py
```

التفاصيل الكاملة موجودة في [`quran_tiktok/README.md`](./quran_tiktok/README.md).
